ПРОБЛЕМА:
---------
В Desktop Word (программа на компьютере) надстройка не видна.
"Мои надстройки" открывает магазин.

Это НОРМАЛЬНО для разработческих надстроек!


РЕШЕНИЕ (выберите ОДНО):
-------------------------

╔═══════════════════════════════════════════════════════════╗
║  СПОСОБ 1: Word Online (РЕКОМЕНДУЮ!)                     ║
╚═══════════════════════════════════════════════════════════╝

1. Откройте https://office.com в браузере
2. Войдите в Microsoft аккаунт
3. Word → Новый документ
4. Вставка → Надстройки Office
5. "Отправить мою надстройку" (внизу)
6. Выберите manifest.xml
7. Отправить

✓ РАБОТАЕТ 100%! Кнопки появятся сразу!


╔═══════════════════════════════════════════════════════════╗
║  СПОСОБ 2: Автоматическая установка                      ║
╚═══════════════════════════════════════════════════════════╝

В PowerShell:

cd C:\Users\ВашеИмя\Downloads\word-add-in\frontend
npm install -g office-addin-debugging
office-addin-debugging start manifest.xml desktop

✓ Word откроется с надстройкой автоматически!


╔═══════════════════════════════════════════════════════════╗
║  СПОСОБ 3: Двойной клик на bat файл                      ║
╚═══════════════════════════════════════════════════════════╝

Дважды кликните на файл:
    install-to-word-windows.bat

Следуйте инструкциям на экране.


ЧТО ДЕЛАТЬ ПОСЛЕ УСТАНОВКИ:
----------------------------
1. Убедитесь что Backend запущен:
   docker-compose up -d

2. Убедитесь что Frontend запущен:
   cd frontend
   npm run serve

3. В Word нажмите кнопку "Параметры БД"

4. Должна открыться панель с таблицей!


ЕСЛИ НЕ РАБОТАЕТ:
------------------
→ Используйте Word Online (office.com) - это всегда работает!
→ Или читайте: WINDOWS_УСТАНОВКА_НАДСТРОЙКИ.md


БЫСТРАЯ ПРОВЕРКА:
-----------------
1. Backend работает?
   Откройте: http://localhost:8000/docs

2. Frontend работает?
   Откройте: https://localhost:3000

3. Оба работают?
   → Тогда проблема только с установкой в Word
   → Используйте Word Online!
