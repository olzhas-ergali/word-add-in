# 🔄 Как это работает теперь

## Новая логика: API только для загрузки, всё остальное - БД

---

## 📋 Процесс работы:

### 1️⃣ Загрузка шаблона (ОДИН РАЗ из API)

```
Пользователь → "Загрузить шаблон" в Word
    ↓
Backend → Получить список шаблонов из Printable Forms API
    ↓
Пользователь выбирает шаблон
    ↓
Backend → Загрузить .docx из Printable Forms API
    ↓
Backend → Автоматически извлечь переменные:
    - Найти все {VARIABLE}
    - Найти все {{VARIABLE}}
    - Найти все [VARIABLE]
    ↓
Backend → Сохранить в PostgreSQL:
    contract_id = TEMPLATE-12345678
    param_name = CLIENT_FIO
    param_value = "" (пусто)
    description = "Из шаблона ДДУ.docx"
    ↓
Frontend → Показать "Найдено 38 параметров, сохранено в БД"
    ↓
Frontend → Вставить документ в Word
```

**Результат:** 
- ✅ Документ в Word
- ✅ Параметры в БД (пустые, нужно заполнить)

---

### 2️⃣ Заполнение значений параметров (В БД, БЕЗ API)

```
Пользователь → "Параметры БД" в Word
    ↓
Frontend → Показать таблицу параметров из БД
    ↓
Пользователь заполняет значения:
    CLIENT_FIO = "Иванов Иван Иванович"
    CONTRACT_NUMBER = "ADL-1-204/41"
    APARTMENT_NUMBER = "204"
    ↓
Frontend → Сохранить в БД через API:
    PUT /api/params/update/{id}
    ↓
PostgreSQL → Обновить записи
```

**Результат:**
- ✅ Все параметры заполнены в БД
- ❌ API не используется

---

### 3️⃣ Заполнение документа (ИЗ БД, БЕЗ API)

```
Пользователь → Открывает документ в Word
Пользователь → Нажимает "Заполнить данные"
    ↓
Frontend → Спросить Contract ID (или взять из localStorage)
    ↓
Frontend → Получить параметры из БД:
    GET /api/params/contract/{contract_id}
    ↓
PostgreSQL → Вернуть все параметры с значениями
    ↓
Frontend → В документе Word:
    Найти {CLIENT_FIO} → Заменить на "Иванов Иван Иванович"
    Найти {CONTRACT_NUMBER} → Заменить на "ADL-1-204/41"
    Найти {APARTMENT_NUMBER} → Заменить на "204"
    ↓
Документ заполнен!
```

**Результат:**
- ✅ Документ заполнен данными из БД
- ❌ API вообще не используется

## 📊 Схема данных:

```
┌─────────────────────────────────────────────┐
│  Printable Forms API                        │
│  (используется РЕДКО - только загрузка)     │
└──────────────┬──────────────────────────────┘
               │
               │ 1 раз при загрузке нового шаблона
               ↓
┌─────────────────────────────────────────────┐
│  Python Backend                              │
│  /api/templates/download/{id}                │
│  - Загружает .docx                          │
│  - Извлекает переменные                     │
│  - Сохраняет в БД                           │
└──────────────┬──────────────────────────────┘
               │
               ↓
┌─────────────────────────────────────────────┐
│  PostgreSQL (contract_parameters)            │
│                                              │
│  id | contract_id    | param_name | value   │
│  ---|----------------|------------|-------- │
│  1  | TEMPLATE-1234  | CLIENT_FIO | Иванов  │
│  2  | TEMPLATE-1234  | CONTRACT_# | ADL-1   │
│  3  | DDU-2024-001   | CLIENT_FIO | Петров  │
│                                              │
│  ← Здесь хранятся ВСЕ параметры             │
└──────────────┬──────────────────────────────┘
               │
               │ Все операции
               ↓
┌─────────────────────────────────────────────┐
│  Word Add-in (Frontend)                      │
│  - Параметры БД (CRUD)                      │
│  - Заполнение документов (из БД)            │
└─────────────────────────────────────────────┘
```

## 🎯 Обращения к API:

### Когда API используется:
- ✅ **Один раз:** Загрузка нового шаблона
- ✅ **Редко:** Обновление списка шаблонов

### Когда API НЕ используется:
- ❌ Получение значений параметров → **БД**
- ❌ Сохранение параметров → **БД**
- ❌ Редактирование параметров → **БД**
- ❌ Заполнение документов → **БД**
- ❌ Поиск параметров → **БД**

---

## 📈 Сравнение запросов:

### Было (всё через API):

```
Загрузка документа:
1. GET /api/templates/list → API
2. GET /api/documents/download/{id} → API
3. GET /api/variables/document/{id} → API
4. POST /api/variables/values → API

Заполнение документа:
5. POST /api/variables/values → API

ИТОГО: 5 запросов к внешнему API
```

### Стало (только загрузка через API):

```
Загрузка шаблона (один раз):
1. GET /api/templates/list → API
2. POST /api/templates/download/{id} → API → БД

Заполнение параметров (много раз):
3. GET /api/params/contract/{id} → БД
4. PUT /api/params/update/{id} → БД

Заполнение документа (много раз):
5. GET /api/params/contract/{id} → БД

ИТОГО: 2 запроса к API (один раз при загрузке)
       ВСЕ остальные операции - локальная БД
```

## 💡 Преимущества:

| Параметр | Через API | Через БД |
|----------|-----------|----------|
| **Скорость** | 2-5 сек | 0.1 сек ⚡ |
| **Зависимость от сети** | Всегда нужна | Не нужна ✅ |
| **Offline режим** | Не работает | Работает ✅ |
| **Редактирование** | Сложно | Легко (UI) ✅ |
| **Количество запросов** | Много | Минимум ✅ |
| **Нагрузка на API** | Высокая | Минимальная ✅ |

## 🔧 Что изменилось в коде:

### Backend:

**Отключены:**
- ❌ `/api/documents/*` - не используется
- ❌ `/api/variables/*` - не используется
- ❌ `/api/auth/*` - не используется

**Активны:**
- ✅ `/api/templates/list` - список из API
- ✅ `/api/templates/download/{id}` - загрузка + автосохранение
- ✅ `/api/params/*` - CRUD для БД

### Frontend:

**Изменено:**
- ✅ `templates.html` - новая страница загрузки (вместо documents.html)
- ✅ `commands.html` - заполнение из БД (вместо API)
- ✅ `manifest.xml` - обновлены кнопки

## 🎯 Как использовать:

### Первый раз (загрузка шаблона):

1. **Загрузить шаблон** → выбрать из API
2. Система автоматически:
   - Загрузит .docx
   - Найдет все `{ПАРАМЕТРЫ}`
   - Сохранит в БД
3. **Параметры БД** → заполнить значения

### Постоянная работа (без API):

1. **Параметры БД** → редактировать значения
2. **Заполнить данные** → документ заполнится из БД
3. Всё работает **offline**!
