## Вариант 1: С Docker (проще всего!)

### Что нужно:
- Docker Desktop
- Node.js

---

### ШАГ 1: Установите Docker Desktop

Скачайте и установите:
- https://www.docker.com/products/docker-desktop

Запустите Docker Desktop и подождите пока иконка станет зеленой.

---

### ШАГ 2: Запустите Backend + PostgreSQL

Откройте **Terminal** и выполните:

```bash
# Перейдите в папку проекта
cd /Users/onyoka/Downloads/word-add-in

# Запустите Docker контейнеры
docker-compose up -d
```

Подождите 10-20 секунд. Затем проверьте:

```bash
# Проверка что контейнеры запущены
docker-compose ps
```

Должны увидеть:
```
NAME            STATUS          PORTS
pf-postgres     Up (healthy)    0.0.0.0:5432->5432/tcp
pf-backend      Up              0.0.0.0:8000->8000/tcp
```

Проверьте Backend в браузере:
- Откройте: http://localhost:8000/docs
- Должен открыться Swagger UI

✅ **Backend готов!**

---

### ШАГ 3: Запустите Frontend

## Вариант 2: БЕЗ Docker (нужен PostgreSQL)

### Что нужно установить:
- Python 3.11+
- Node.js 18+
- PostgreSQL 16

---

### ШАГ 1: Установите PostgreSQL

**На Mac:**
```bash
brew install postgresql@16
brew services start postgresql@16
```

**На Windows:**
Скачайте и установите: https://www.postgresql.org/download/windows/

---

### ШАГ 2: Создайте базу данных

```bash
# Создайте БД
psql -U postgres -c "CREATE DATABASE printable_forms;"

# Создайте таблицу
cd /Users/onyoka/Downloads/word-add-in/backend
psql -U postgres -d printable_forms -f create_params_table.sql
```

Введите пароль от PostgreSQL если попросит.

---

### ШАГ 3: Настройте Backend

```bash
cd /Users/onyoka/Downloads/word-add-in/backend

# Создайте виртуальное окружение Python
python3 -m venv venv

# Активируйте его
source venv/bin/activate
# На Windows: venv\Scripts\activate

# Установите зависимости
pip install -r requirements.txt

# Создайте .env файл
cp .env.example .env
```

Откройте файл `.env` и измените:
```env
DATABASE_PASSWORD=ваш_пароль_от_postgres
USE_DATABASE_DIRECT=True
```

---

### ШАГ 4: Запустите Backend

```bash
# В папке backend с активированным venv
python run.py
```

Должны увидеть:
```
INFO:     Uvicorn running on http://0.0.0.0:8000
```

Проверьте: http://localhost:8000/docs

✅ **Backend запущен!**

---

### ШАГ 5: Запустите Frontend

**Откройте НОВЫЙ терминал:**

```bash
cd /Users/onyoka/Downloads/word-add-in/frontend

npx office-addin-dev-certs install
```

## ❓ FAQ

### Q: Какой вариант выбрать?

**A:**
- Для разработки и тестирования: **Вариант 1 (Docker)**
- Для production сервера: **Вариант 2 (без Docker)** с настроенным PostgreSQL
- Для демонстрации: **Вариант 3 (только Frontend)**

### Q: Где хранятся данные в Docker?

**A:** В Docker volume `postgres_data`. Данные сохраняются даже после перезапуска.

### Q: Как удалить все данные?

**A:**
```bash
docker-compose down -v  # -v удаляет volumes
```

### Q: Можно ли использовать другую БД (MySQL)?

**A:** Да, нужно изменить `docker-compose.yml` и заменить `asyncpg` на `aiomysql` в Python коде.

### Q: Как посмотреть что в БД?

**A:**
```bash
docker exec -it pf-postgres psql -U postgres -d printable_forms
```

Затем:
```sql
SELECT * FROM contract_parameters;
\q
```
