# 🔄 Новый Workflow - Только БД, API только для загрузки

## Что изменилось:

### ❌ Было (постоянные обращения к API):
```
1. Пользователь выбирает шаблон
   → API запрос

2. Загрузка документа  
   → API запрос

3. Получение переменных
   → API запрос

4. Получение значений переменных
   → API запрос

5. Заполнение документа
   → API запрос
```

**Итого:** 5 запросов к API на каждый документ!

---

### ✅ Стало (API только один раз):
```
1. Пользователь выбирает шаблон
   → Показывается список из API (один раз)

2. Загрузка документа
   → API запрос
   → Автоматическое извлечение параметров
   → Сохранение в БД
   
3. Редактирование параметров
   → Работа с БД (без API)

4. Заполнение документа
   → Чтение из БД (без API)

5. Все последующие действия
   → Только БД (без API)
```

**Итого:** Только 1-2 запроса к API при загрузке шаблона!

---

## 🔄 Новый процесс работы:

### Шаг 1: Загрузка шаблона (один раз)

1. Нажмите **"Загрузить шаблон"** в Word
2. Выберите шаблон из списка (список из API)
3. Нажмите **"Загрузить и сохранить параметры"**

**Что происходит:**
- ✅ Документ загружается из Printable Forms API
- ✅ Автоматически извлекаются все переменные `{VAR}`, `{{VAR}}`, `[VAR]`
- ✅ Параметры сохраняются в БД
- ✅ Документ открывается в Word

**Результат:** Все параметры теперь в вашей БД!

---

### Шаг 2: Редактирование параметров (в БД)

1. Нажмите **"Параметры БД"** в Word
2. Найдите параметры загруженного шаблона
3. Заполните значения для каждого параметра
4. Сохраните

**Пример:**
```
Contract ID: TEMPLATE-12345678
Параметр: CLIENT_FIO
Значение: Иванов Иван Иванович  ← Вы вводите
```

---

### Шаг 3: Заполнение документа (из БД)

1. Откройте документ в Word
2. Нажмите **"Заполнить данные"**
3. Параметры автоматически заполнятся **из БД**

**API не используется!** Всё из локальной БД.

## 🎯 Преимущества нового подхода:

|----------|-------------------|------------|

| **Запросов к API** | 5+ на документ | 1-2 при загрузке |

| **Offline режим** | ❌ Не работает | ✅ Работает |
| **Редактирование параметров** | ❌ Сложно | ✅ Легко (UI) |

## 📝 Что отключено:

### Отключенные endpoints:
- ❌ `/api/documents/*` - заменен на `/api/templates/*`
- ❌ `/api/variables/*` - данные теперь из БД
- ❌ `/api/auth/*` - авторизация не используется

### Новые endpoints:
- ✅ `/api/templates/list` - список шаблонов из API
- ✅ `/api/templates/download/{id}` - загрузка + автосохранение в БД
- ✅ `/api/templates/download/{id}/file` - только файл
- ✅ `/api/params/*` - полный CRUD для параметров в БД

## 🔧 Что настроено:

### 1. Автоматическое извлечение параметров

Поддерживаются форматы:
- `{PARAMETER_NAME}`
- `{{PARAMETER_NAME}}`
- `[PARAMETER_NAME]`
- `${PARAMETER_NAME}`

### 2. Автоматическое сохранение

При загрузке шаблона:
```python
# Автоматически:
1. Извлекает переменные из документа
2. Создает записи в БД:
   - contract_id = TEMPLATE-{document_id}
   - param_name = имя переменной
   - param_value = пусто (заполните вручную)
   - description = "Автоматически извлечено из {имя файла}"
```

### 3. UI для редактирования

После загрузки идите в **"Параметры БД"** и заполните значения.
