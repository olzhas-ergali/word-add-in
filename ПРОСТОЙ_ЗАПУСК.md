# 🎯 САМЫЙ ПРОСТОЙ ЗАПУСК

## 3 шага до успеха!

---

## Шаг 1: Установите Docker

Скачайте и установите **Docker Desktop**:
- **Mac**: https://www.docker.com/products/docker-desktop
- **Windows**: https://www.docker.com/products/docker-desktop

После установки запустите Docker Desktop.

---

## Шаг 2: Запустите проект

Откройте Terminal и выполните **2 команды**:

### Команда 1 - Запуск Backend + База данных:
```bash
cd /Users/onyoka/Downloads/word-add-in
./docker-start.sh
```

Подождите 10-15 секунд. Должны увидеть:
```
Backend: OK
PostgreSQL: OK
```

### Команда 2 - Запуск Frontend (НОВЫЙ ТЕРМИНАЛ):
```bash
cd /Users/onyoka/Downloads/word-add-in
./frontend-start.sh
```

Должны увидеть:
```
Server running at https://localhost:3000
```

✅ **Всё запущено!**

---

## Шаг 3: Установите в Word

1. Откройте **Microsoft Word**
2. Создайте новый документ
3. **Insert** → **Add-ins** → **My Add-ins**
4. **Upload My Add-in**
5. Выберите файл: `/Users/onyoka/Downloads/word-add-in/frontend/manifest.xml`
6. Нажмите **Upload**

✅ **Готово!** Теперь в Word есть кнопки **"Печатные формы"**!

---

## 🎉 Используйте!

### 1. Откройте "Параметры БД"
Нажмите кнопку в Word → увидите таблицу с параметрами

### 2. Добавьте свои данные
Раскройте "➕ Добавить новый параметр" и заполните

### 3. Заполняйте документы
Нажмите "Заполнить данные" - переменные заполнятся автоматически!

---

## 🛑 Остановка

```bash
docker-compose down  # Остановить Backend + БД
# Frontend остановите через Ctrl+C в терминале
```

---

## ❓ Проблемы?

### Docker не запускается
1. Запустите Docker Desktop
2. Подождите пока значок Docker станет зеленым

### Backend не работает
```bash
docker-compose logs backend
```

### База данных не работает
```bash
docker-compose logs db
```

### Frontend не запускается
```bash
cd frontend
npm install  # Переустановить зависимости
```
