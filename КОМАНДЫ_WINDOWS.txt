СПОСОБ 1: АВТОМАТИЧЕСКИЙ (двойной клик)
----------------------------------------
Просто дважды кликните на файл:
    start-windows.bat

Всё запустится автоматически!


СПОСОБ 2: ВРУЧНУЮ (PowerShell команды)
---------------------------------------

ТЕРМИНАЛ 1 (PowerShell - Backend):
-----------------------------------
cd C:\Users\ВашеИмя\Downloads\word-add-in
docker-compose up -d
Start-Sleep -Seconds 15
Invoke-WebRequest http://localhost:8000/health

✓ Если увидели JSON - Backend работает!


ТЕРМИНАЛ 2 (PowerShell - Frontend):
------------------------------------
cd C:\Users\ВашеИмя\Downloads\word-add-in\frontend
npm install
npx office-addin-dev-certs install
npm run serve

✓ Если увидели "Server running" - Frontend работает!


УСТАНОВКА В WORD (выберите один способ):
-----------------------------------------

СПОСОБ А - Word Online (рекомендуется):
1. Откройте https://office.com
2. Word Online → Новый документ
3. Вставка → Надстройки Office
4. "Отправить мою надстройку" (внизу)
5. Выберите manifest.xml
6. Отправить

СПОСОБ Б - Автоматом (Desktop Word):
cd C:\Users\ВашеИмя\Downloads\word-add-in\frontend
npm install -g office-addin-debugging
office-addin-debugging start manifest.xml desktop

(Word откроется с надстройкой автоматически!)

СПОСОБ В - Через сетевую папку:
1. Создать папку:
   mkdir %LOCALAPPDATA%\Microsoft\Office\16.0\Wef

2. Скопировать манифест:
   copy manifest.xml %LOCALAPPDATA%\Microsoft\Office\16.0\Wef\

3. В Word: Файл → Параметры → Центр управления безопасностью
   → Параметры центра управления безопасностью
   → Надежные каталоги надстроек
   → Добавить: %LOCALAPPDATA%\Microsoft\Office\16.0\Wef
   → Поставить галочку "Показывать в меню"

4. Перезапустить Word

5. Вставка → Мои надстройки → ОБЩАЯ ПАПКА
