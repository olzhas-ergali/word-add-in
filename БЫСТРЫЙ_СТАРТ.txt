ТЕРМИНАЛ 1 (Backend):
---------------------
cd /Users/onyoka/Downloads/word-add-in
docker-compose up -d
sleep 15
curl http://localhost:8000/health

✓ Если увидели JSON - Backend работает!


ТЕРМИНАЛ 2 (Frontend):
---------------------
cd /Users/onyoka/Downloads/word-add-in/frontend
npm install
npx office-addin-dev-certs install
npm run serve

✓ Если увидели "Server running at https://localhost:3000" - Frontend работает!


WORD (Установка):
-----------------
СПОСОБ 1 (проще): Word Online
1. Откройте https://office.com
2. Word Online → Новый документ
3. Insert → Office Add-ins → Upload My Add-in
4. Выберите manifest.xml
5. Upload

СПОСОБ 2 (автоматом):
cd /Users/onyoka/Downloads/word-add-in/frontend
npm install -g office-addin-debugging
office-addin-debugging start manifest.xml desktop

СПОСОБ 3 (Mac Desktop):
1. Скопируйте манифест:
   cp /Users/onyoka/Downloads/word-add-in/frontend/manifest.xml \
      ~/Library/Containers/com.microsoft.Word/Data/Documents/wef/
2. Перезапустите Word
3. Insert → Add-ins (надстройка появится в списке)

✓ На ленте Word появятся кнопки "Печатные формы"!

📖 Подробно: УСТАНОВКА_В_WORD.md
