**Время запуска**: 30-60 секунд при первом запуске, 10-15 секунд при последующих.

## 🔧 Управление

### Перезапустить всё:
```bash

```

```bash

```

### Только запустить Docker:
```bash
docker-compose up -d
```

## ❓ Решение проблем

### Ошибка: "Docker не запущен"

**Решение:**
1. Запустите Docker Desktop
2. Подождите пока значок станет зеленым
3. Запустите скрипт снова

### Ошибка: "Port 8000 is already in use"

**Решение:**
```bash
# Остановите старые контейнеры
docker-compose down

# Или найдите и убейте процесс
lsof -i :8000
kill -9 <PID>
```

### Ошибка: "Port 3000 is already in use"

**Решение:**
```bash
# Найдите процесс
lsof -i :3000

# Убейте его
kill -9 <PID>
```

### Ошибка: npm install не работает

**Решение:**
```bash
cd frontend
rm -rf node_modules package-lock.json
npm install
```

### Ошибка: SSL сертификаты не устанавливаются

**Решение:**
```bash
cd frontend
npx office-addin-dev-certs install --force
```

Может потребовать ваш пароль Mac для установки сертификата.

## 💡 Советы

### 1. Держите терминал открытым
Не закрывайте терминал где запущен скрипт - там работает Frontend.

### 2. Логи в реальном времени
Backend и PostgreSQL логи можно смотреть:
```bash
docker-compose logs -f
```

### 3. Первый запуск медленнее
Docker нужно скачать образы и собрать backend (1-2 минуты).
Последующие запуски - 10-15 секунд.

### 4. Данные сохраняются
PostgreSQL использует Docker volume - данные не теряются при перезапуске.

### 5. Hot reload работает
При изменении Python кода backend перезагружается автоматически.
