# 🖐️ Запуск вручную (копируй и вставляй команды)

## Вариант А: С Docker (Backend в Docker, Frontend вручную)

---

### ТЕРМИНАЛ 1 - Backend + PostgreSQL (Docker)

Скопируйте и вставьте эти команды по порядку:

```bash
# 1. Перейти в папку проекта
cd /Users/onyoka/Downloads/word-add-in

# 2. Запустить Docker контейнеры
docker-compose up -d

# 3. Подождать 15 секунд
sleep 15

# 4. Проверить что запустилось
docker-compose ps

# 5. Проверить Backend
curl http://localhost:8000/health
```

Если всё ОК, увидите JSON с "status": "healthy"

✅ **Backend готов!** Оставьте этот терминал открытым.

---

### ТЕРМИНАЛ 2 - Frontend (вручную)

Откройте **НОВЫЙ терминал** и выполните:

✅ **Frontend готов!** Оставьте этот терминал открытым.

## Вариант Б: БЕЗ Docker (всё вручную)

Если нет Docker, нужен PostgreSQL.

---

### ТЕРМИНАЛ 1 - PostgreSQL (должен быть установлен!)

```bash
# Проверить что PostgreSQL установлен
psql --version

# Если не установлен:
# Mac: brew install postgresql@16
# Mac: brew services start postgresql@16

# Создать базу данных
psql -U postgres -c "CREATE DATABASE printable_forms;"

# Создать таблицу
cd /Users/onyoka/Downloads/word-add-in/backend
psql -U postgres -d printable_forms -f create_params_table.sql
```

✅ **PostgreSQL готов!**

---

### ТЕРМИНАЛ 2 - Backend (Python вручную)

```bash
# 1. Перейти в папку backend
cd /Users/onyoka/Downloads/word-add-in/backend

# 2. Создать виртуальное окружение (ТОЛЬКО ПЕРВЫЙ РАЗ!)
python3 -m venv venv

# 3. Активировать его
source venv/bin/activate

# 4. Установить зависимости (ТОЛЬКО ПЕРВЫЙ РАЗ!)
pip install -r requirements.txt

# 5. Создать .env (ТОЛЬКО ПЕРВЫЙ РАЗ!)
cp .env.example .env
# ВАЖНО: Откройте .env и измените DATABASE_PASSWORD на ваш пароль от PostgreSQL!

# 6. Запустить backend
python run.py
```

Должны увидеть:
```
INFO: Uvicorn running on http://0.0.0.0:8000
```

✅ **Backend готов!** Оставьте терминал открытым.

## ❓ Проблемы?

### "docker-compose: command not found"

Установите Docker Desktop: https://www.docker.com/products/docker-desktop

### "Port 8000 already in use"

```bash
# Остановить Docker
docker-compose down

# Или найти процесс
lsof -i :8000
kill -9 <PID>
```

### "Port 3000 already in use"

```bash
lsof -i :3000
kill -9 <PID>
```

### "npm: command not found"

Установите Node.js: https://nodejs.org/

### Backend не подключается к БД

Проверьте файл `backend/.env`:
```bash
cat backend/.env | grep DATABASE
```

Должно быть:
```
DATABASE_HOST=db              # Для Docker
# или
DATABASE_HOST=localhost       # Без Docker
```

## 💡 Полезные команды:

### Посмотреть логи Docker:
```bash
docker-compose logs -f backend
docker-compose logs -f db
```

### Зайти в PostgreSQL:
```bash
docker exec -it pf-postgres psql -U postgres -d printable_forms
```

Команды в psql:
```sql
-- Посмотреть параметры
SELECT * FROM contract_parameters;

-- Посмотреть таблицы
\dt

-- Выйти
\q
```

### Перезапустить Backend (Docker):
```bash
docker-compose restart backend
```

### Полностью пересобрать (если изменили код):
```bash
docker-compose up -d --build
```
